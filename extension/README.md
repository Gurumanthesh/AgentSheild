# AgentShield Extension

## Chrome installation

1. Open Chrome.
2. Navigate to `chrome://extensions`.
3. Enable Developer mode.
4. Click Load unpacked.
5. Select the AgentShield project root directory.
6. Pin AgentShield to the toolbar.
7. Open a normal webpage or the demo page in `demo/test-page.html`.
8. Click the AgentShield icon.
9. Click Analyze this page.
10. Review the risk result and explanation.

## Demo notes

- The demo page contains benign and suspicious examples.
- The extension uses local heuristic detection as the default fallback.
- Backend analysis is optional and improves structured scoring.
